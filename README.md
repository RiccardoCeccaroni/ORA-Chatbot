# ORA Chatbot — monorepo

A personal portfolio repo containing two AI projects built around the published material of **ORA!**, an Italian centrist party founded by Michele Boldrin and Alberto Forchielli.

> **Disclaimer.** This is a personal project. The corpus consists of publicly available party material used here for technical experimentation. Anything generated by these systems represents the output of an information-retrieval pipeline, not the party's official voice.

## [`chatbot/`](./chatbot/) — Agentic-RAG chatbot

An Italian-language chatbot that answers questions about ORA!'s positions, the views of its leaders, and how ORA! compares to other Italian parties. Built end-to-end:

- **Corpus** curated across four trust tiers — party voice (manifesto, comunicati, newsletter), leader views (Boldrin, Forchielli — always cited as personal), other Italian parties (retrieved only on explicit comparisons), and ISTAT statistical data for empirical questions.
- **Ingestion pipeline** that chunks the corpus, embeds it with Voyage `voyage-4-large`, and ingests into a Qdrant Cloud vector store.
- **Agent runtime** with retrieval + rerank (Voyage `voyage-rerank-2.5`), a synthesizer (Claude Opus 4.7), a verifier pass over claims (Claude Haiku 4.5), and explicit refusal when the corpus is silent rather than inventing positions.
- **25 architectural decisions** in [`chatbot/decisions/`](./chatbot/decisions/) documenting every fork (chunking, embedding, retrieval strategy, generation model, guardrails, evaluation, persona).

Entry point: [`chatbot/agent/cli.py`](./chatbot/agent/cli.py). Full design rationale: [`chatbot/decisions/`](./chatbot/decisions/).

## [`ora-mcp/`](./ora-mcp/) — MCP server

A public MCP (Model Context Protocol) server that exposes the same corpus to any AI assistant speaking MCP — Claude Desktop, Cursor, ChatGPT with MCP, claude.ai web custom connectors. Instead of generating answers itself, the server lets the user's own AI retrieve and cite ORA! material verbatim.

- **Live at** `https://ora-mcp-claudeai.fly.dev`, deployed on Fly.io (Frankfurt).
- **Two tools** — `find_position(topic, …)` returns structured trust-hierarchy buckets (official party, leader views, supporting data, optional comparison); `data_lookup(metric, …)` returns curated stat-cards.
- **Five resources** — the full manifesto (21 thesis files), party bylaws, policy fundamentals, code of ethics, and a trust-hierarchy guide.
- **OAuth 2.1** (permissive provider) for compatibility with claude.ai's web connector flow.
- **Streamable HTTP** transport, `FastMCP` + Starlette, deployed as a single Docker image.
- **105-test acceptance suite** in [`ora-mcp/tests/`](./ora-mcp/tests/) producing a PDF verdict report.

Design + operations: [`ora-mcp/DECISIONS.md`](./ora-mcp/DECISIONS.md), [`ora-mcp/LEARNINGS.md`](./ora-mcp/LEARNINGS.md), [`ora-mcp/README.md`](./ora-mcp/README.md).
